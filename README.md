# Hidden Settings
Hidden Settings allows the user to change Terraria settings that are hidden or inacessible while in the main menu or in world using this mod's mod config page.
Each setting has a detailed explanation on what it does as well as what it is set to by default.
This mod is client sided which means you can join multiplayer games without everyone playing needing to have it enabled.

## Usually Only Available In Game
These settings normally require you to join a world to change. This mod lets you change them from the main menu.
* Smart Doors
* Autofire
* Zoom
* UI Scale
* Map Scale
* Hover Text Boxes
* Heat Distortion
* Storm Effects
* Waves Quality
* Hover Controls

## Usually Only Available On Main Menu
These settings normally only accessible on the main menu and cannot be changed while in a world. This mod lets you change them while in a world.
* Map
* Passwords
* Borderless Window
* Miners Wobble
* Quick Trash
* Attack Speed Effect Tooltips
* Remove Forced Minimum Zoom
